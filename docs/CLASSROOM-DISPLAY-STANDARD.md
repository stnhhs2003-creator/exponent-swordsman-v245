# 星賢數學遊戲中心：教室大屏永久開發規格
適用所有現有及未來遊戲。教室大屏單人觸控優先，手機獨立適配。
- 戰鬥區固定16:9，使用可視寬高共同限制：scale=min(availableWidth/designWidth,availableHeight/designHeight)，不拉伸、不裁切。HUD、題目、操作區及安全邊距均納入高度預算。
- 使用100dvh與visualViewport resize，兼容Safari工具列、旋轉、全螢幕及安全區；遊戲中不可要求捲動或縮放。首頁可正常捲動。
- 左手方向鍵/搖桿、右手跳躍/攻擊/技能，兩組緊鄰且集中下方中央，不可分居兩側；建議中心距依實機可達性調整，手機觸控目標至少44 CSS px。保留鍵盤及多點觸控，放手、失焦、pointercancel清除輸入。
- 返回、音量及設定不得遮擋遊戲或操作區；退出需防誤觸。
- 課堂大屏預設，手機橫向獨立排版；不要改題庫、玩法或素材以修復版面。
- 每次發布前驗收1920x1080、1280x720、1366x768、手機橫向含瀏覽器工具列；確認題目、主角、敵人、所有控制鍵完整可見、無橫直捲動，單人雙手同時移動及攻擊。檢查開始、結算、重玩、音效及轉向。
- 自動化測試應檢查元素 bounding rect 在可視區內、控制群組距離、比例及無溢出；實機人體工學另行驗收。未通過不得標示正式驗收成功。
- 更新前保留可回滾版本；測試通過再更新正式入口；確認部署頁版本與提交一致，不能僅憑提交成功聲稱上線。
- 新遊戲應共用版面與控制模組；舊遊戲逐一遷移，不可盲目套用破壞原玩法。
