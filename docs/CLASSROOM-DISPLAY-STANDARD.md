# 星賢數學遊戲中心：教室大屏永久開發規格
適用所有現有及未來遊戲。教室大屏單人觸控優先，手機獨立適配。
- 教室大屏以16:9整體可視區為參考；各遊戲戰鬥區比例依玩法獨立決定，保持素材原比例，使用可視寬高共同限制：scale=min(availableWidth/designWidth,availableHeight/designHeight)，不拉伸、不裁切。HUD、題目、操作區及安全邊距均納入高度預算。
- 使用100dvh與visualViewport resize，兼容Safari工具列、旋轉、全螢幕及安全區；遊戲中不可要求捲動或縮放。首頁可正常捲動。
- 左手方向鍵/搖桿、右手跳躍/攻擊/技能，單人動作遊戲兩組緊鄰且集中於可達範圍，具體位置依玩法與實機決定；雙人競賽保留雙方獨立操作區；建議中心距依實機可達性調整，手機觸控目標至少44 CSS px。保留鍵盤及多點觸控，放手、失焦、pointercancel清除輸入。
- 返回、音量及設定不得遮擋遊戲或操作區；退出需防誤觸。
- 課堂大屏預設，手機橫向獨立排版；不要改題庫、玩法或素材以修復版面。
- 每次發布前驗收1920x1080、1280x720、1366x768、手機橫向含瀏覽器工具列；確認題目、主角、敵人、所有控制鍵完整可見、無橫直捲動，單人雙手同時移動及攻擊。檢查開始、結算、重玩、音效及轉向。
- 自動化測試應檢查元素 bounding rect 在可視區內、控制群組距離、比例及無溢出；實機人體工學另行驗收。未通過不得標示正式驗收成功。
- 更新前保留可回滾版本；測試通過再更新正式入口；確認部署頁版本與提交一致，不能僅憑提交成功聲稱上線。
- 僅共用可視範圍計算、輸入安全、音訊恢復及驗收工具；版面與控制配置各遊戲獨立設計，不強制套用同一模板。

## 永久音訊規格（所有遊戲）
- 背景音樂 BGM、音效 SFX 使用獨立音量匯流排，配樂清楚但不蓋過題目提示，避免削波；預設配樂開啟，尊重使用者手動靜音。
- 音訊須由可信任的點擊/觸控/鍵盤手勢解鎖，處理 AudioContext suspended/interrupted 及 resume 失敗；不可假設 Safari 支援無手勢自動播放。
- 切換大屏、全螢幕、旋轉、頁面可見性、焦點、pageshow 後恢復原配樂；若瀏覽器拒絕，提供清楚且不遮擋的啟用音訊控制。
- 管理單一音樂排程或播放實例；切換場景/Boss、暫停、結算、重玩時正確停止、切換或恢復，不重疊、不累積計時器。
- 音效與配樂音量分開可調，設定收合且不干擾單人操作；不因大屏模式而靜音。
- 發布前分別驗收配樂與音效：首次開始、切換大屏、全螢幕、iPhone Safari 橫向、背景返回、Boss、結算、重玩、手動靜音及恢復。需驗證實際可聽聲音，不能僅以程式存在或部署成功當作通過。
- 新遊戲共用經驗證的音訊模組；舊遊戲逐款遷移並保留原配樂及玩法，不擅自更換素材。

## 螢幕旋轉與進度保護
- 大屏與手機橫向皆可使用橫向版面；模式由使用者選擇，不以方向自動切換。
- resize、orientationchange、fullscreenchange 只調整版面，不重建關卡、不返回首頁、不重新載入。
- 旋轉或失焦時清理觸控狀態，防止卡鍵及誤射；短暫調整期間保護計時與生命值。
- 遊戲中保存必要的關卡狀態；意外重載後安全恢復，正常結算或主動退出清除暫存。返回按鈕需確認。
- 驗收直向轉橫向、橫向轉直向、全螢幕切換、背景返回及重載恢復；核對題目、分數、生命、計時與配樂，不得只驗收畫面。

## 2026-11-25 穩定化優先／功能凍結
暫停新增遊戲、玩法、非必要美術更新及第三方工具安裝。保留現有14款及原始素材、題庫、音樂、玩法。先盤點所有入口及實際部署版本，再按優先級逐款修復；每款須保留回滾版本，先測試再發布。禁止因大屏切換或旋轉而導航至其他遊戲或總首頁；角色與敵人不可被控制介面遮擋。教室大屏單人操作優先，手機橫向獨立適配；檢查配樂及音效實際可聽、旋轉進度保留、重玩及結算。外部遊戲若無原碼權限，標示限制，不擅自替換。未經實機驗收不得標示完成。全部穩定化驗收後再由教師決定是否解除功能凍結。

## 2026-11-25 修訂：統一品質，不統一版面
禁止把單一遊戲的CSS、畫布比例、人物尺寸、操作位置強制套用所有遊戲。16:9是教室整體顯示的參考，不是每款內部戰場的硬性比例。橫向動作、俯視冒險、雙人競賽、翻牌、打地鼠、棋盤及塔防均須依各自玩法最佳化有效視野、字體、地圖與控制配置。單人操作以雙手可達為準，雙人競賽保留各自答題區。只共用安全區/可視高度、輸入清理、音訊恢復及測試原則。現有遊戲逐款盤點、獨立修復、測試通過後部署；維持功能凍結。
