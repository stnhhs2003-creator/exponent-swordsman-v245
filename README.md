# 指數劍客 V24.5 | GitHub Pages 獨立網站

建議新儲存庫名稱：exponent-swordsman-v245

部署步驟：
1. 在 https://github.com/new 建立一個全新 Public repository，名稱 exponent-swordsman-v245，避免覆蓋任何舊作品。
2. 解壓縮這個 ZIP，將 index.html、assets 資料夾、.nojekyll、README.md 上傳到新儲存庫的根目錄（不要只上傳 ZIP 檔）。
3. 開啟該儲存庫 Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / (root) → Save。
4. 等 GitHub 顯示 Pages 網址，再開啟 https://<你的帳號>.github.io/exponent-swordsman-v245/。

提醒：本壓縮包只是獨立站點素材，並未在 GitHub 建立儲存庫或啟用 Pages。
