# 數學幻境：程式架構與品管 V2.0
本技能是純文字工作流程，借鑑知識圖譜分析方法，不包含 CodeGraph 引擎、MCP、SQLite 索引或遙測。
## 啟動
製作、修正、測試或部署數學遊戲時，搭配既有製作技能使用。先維護現有 13 款，暫停第 14、15 款。
## 分工
製作技能負責規則、數學題庫、角色、場景、音效與實作。本技能負責靜態分析、影響範圍、測試及發布門檻。
## 分析流程
1. 讀取目前分支、入口及實際遊戲清單；記錄基準 commit。不要假設檔名或覆蓋原版。
2. 建立檔案、函式、事件、呼叫、狀態與資源依賴表，標記檔案路徑及行號；單一 HTML 也要追蹤內嵌 JS/CSS。區分已確認和推測。
3. 優先檢查 04 格鬥、05/10 大富翁、螺旋戰機、11 翻牌、12 史萊姆、13 賽車，再檢查其餘實際入口。
4. 每次只做可回復的小幅修改；共用程式先試點再逐步移植，不強行重構。
## P0 教室大屏
1920x1080、1280x720 固定 16:9 預覽；以 contain 等比例縮放，不裁切、不拉伸。手機橫放獨立模式，測試安全區與動態視窗高度。地圖型遊戲左側約 66–70% 地圖、右側題目；動作類保留上方題目及足夠戰鬥區。檢查 Canvas 座標及 pointer 座標轉換、resize、橫直切換、觸控取消及搖桿回中。禁止頁面溢出或按鍵跑位。
## P0 操作與正確性
測試開始、返回首頁、重玩、暫停、計時、勝負、鍵盤及觸控；清理重複 listener、timer 和動畫迴圈。檢查六大單元答案唯一性、分數上下格式、指數上標、括號與負號。格鬥倒數三二一 GO 後才開放作答。音效需符合瀏覽器使用者手勢限制。
## 測試與發布
每款記錄版本、裝置、解析度、步驟、預期、實際、證據、嚴重度、狀態。分開標註靜態確認、模擬測試、實機待驗證；不可把模擬當教室實測。未通過關鍵項不發布正式版。維持既有 URL，先保留可回復 commit，獨立測試後才更新。未取得實機不能宣稱已實測。部署後檢查入口與版本。
## 安全
外部工具安裝前依既定十項檢查：作者、README 權限、完整技能指令、腳本依賴、惡意程式、一鍵安裝、金鑰保護、隔離測試、最小權限、供應鏈。先報告、取得同意，再安裝。不得擅自執行外部腳本或上傳程式碼。
## 輸出
提供架構關係表、P0/P1/P2 問題表、修改範圍、回歸測試及實際部署狀態；提供可追蹤 commit 與未驗證項目。
