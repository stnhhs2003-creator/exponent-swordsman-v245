# 數學空戰｜製作需求與風格規範

## 三個輸入與預設
| 欄位 | 使用者可填 | 未填時 |
|---|---|---|
| 主題 | 海洋、武俠、太空、恐龍、校園、城市、其他 | 海島空戰 |
| 課程單元 | 六單元之一、多單元、自訂國中數學 | 六單元可切換 |
| 風格 | 寫實、卡通、像素、日系、水墨、3D 感、科幻 | 精緻明亮科幻 |

除非使用者另有指示，不再另外要求使用者填平台、題量、Boss、操控鍵、配樂或部署工具等重複欄位；依此預設配置。**「主題」決定世界觀及背景；「課程單元」決定題庫內容；「風格」決定人物／戰機、敵機、Boss、UI、特效、音樂氛圍的視覺一致性**。

## 畫面
- 入口：遊戲標題、三個世界觀選擇卡（或用戶指定選項）、數學單元、開始鍵、玩法、手機／教室大屏切換。
- 遊戲：題目在上方，HUD 顯示命數、得分、能量、關卡；答案四個、位置夠分散，手機觸控與教室遠距都可清楚辨識。
- 背景滾動不得有拼接白線／黑線、拉伸、閃爍；主角與敵機不能卡在 UI 裡。
- 勝利：Boss 倒下、爆炸／煙火／勝利音效與結算；失敗：戰機損毀動畫與重試。
- 道具：武器升級、護盾、補命、速度、全屏炸彈、星星獎勵；功能需與畫面提示一致。

## 圖像防呆（歷史高優先級問題）
- 不能把黑色背景誤認為透明去背；對圖片像素 Alpha 及多個角落檢查。
- 必要時重新去背；如果原素材有黑色陰影，分清陰影與背景，避免把戰機機身誤刪。
- 上傳資產時使用具有版本識別的新檔名，避免手機瀏覽器快取舊圖片。
- 若素材失效，使用明確的 fallback，不能顯示黑框或破圖。

## 操作／關卡
- 左側移動、右側掃射與必殺；鍵盤方向鍵／WASD／空白鍵，按鍵放開即停止。
- 擊落敵機後呈現四個可射擊答案；答題階段可減少攻擊干擾。
- 3 命共用；每關 10 題，Boss 連答 5 題；題目難度由淺到深。
- Boss 必須真的可以失敗／死亡，不能永遠留 1 HP；得分、命數、關卡進度都要在結算前後正確。
- 音效與 BGM 要清楚，但可調整，預設不過大；iPhone 音效要遵守首次點擊解鎖。

## 檢查標準
- 單位題庫正確、答案唯一、上下分數與上標準確。
- iPhone Safari：開始鍵、滑動／點按、旋轉、失焦、回中、沒有捲動干擾。
- 大屏：題目可讀、答案可辨、不遮戰場。
- GitHub Pages：實際部署後檢查 HTML 與二進位 WebP/PNG 連結，而非只看本機檔案。
