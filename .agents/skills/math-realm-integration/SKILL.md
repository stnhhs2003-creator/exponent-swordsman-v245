# 數學幻境｜課程主題一鍵整合

## 三個欄位直接啟動

接受一行或分行輸入「主題、課程單元、風格」，例如：

- 主題：星際能源爭奪｜單元：指數律｜風格：科幻空戰
- 主題：武林試煉｜單元：一元一次方程式｜風格：寫實武俠
- 主題：古堡解謎｜單元：圓心角與圓周角｜風格：3D 奇幻冒險
- 主題：城市商業冒險｜單元：正負數四則｜風格：卡通大富翁

將主題視為世界觀／任務故事，課程單元視為教學目標，風格視為玩法與視覺基調。也接受主題同時是數學單元的簡短說法。依輸入自動決定適合的現有遊戲、難度、題量、戰鬥或競賽規則、畫面、音效、裝置模式及整合方案。若未指定主題或風格，沿用已有最合適的設定；只有缺少核心教學單元，或多個選擇會實質改變成果時，才簡短詢問，不重複要求使用者填寫全部規格。

預設繁體中文（臺灣）、國中課綱程度、由易至難、可反覆練習、答案唯一、題目詳解，以及手機與大屏雙模式。新遊戲以單局約 10 分鐘為課堂設計目標，實際時間依玩法與原版設定調整。修改現有遊戲時，保留此前確認的題量、生命、關卡、計分、難度與原素材，除非使用者明確要求更改。

預設整合到現行八合一入口，保留其他遊戲名稱與連結，不將同款新版本額外列為第九款；只有使用者明確要求新遊戲，才新增卡片。先保留原版可追溯連結，再更新對應卡片。

## 風格與玩法對應

| 風格／玩法 | 優先使用 | 保留與設計重點 |
|---|---|---|

| 寫實武俠、奇幻墨刃 | 指數劍客 | 淵衡／芷言等原角色、兩階平台、答案怪、移動跳躍與必殺 |
| 機甲戰士、橫向集氣射擊 | 螺絲戰機 | BOLT-X 原圖、四大魔王、三種難度、螺絲工坊、排行榜 |
| 格鬥、對戰、競速 | 數學格鬥競技場 | 保留自由競速、同步搶答與拔河；角色動作、勝負特效 |
| 卡通城市、桌遊 | 大富翁 | 答題擲骰、格子走動、多人輪流、勝利格、機會與獎勵 |

| 奇幻解謎、角色冒險 | 式靈大冒險 | 原有世界觀、角色與解題機制；未取得原碼時僅能保留連結 |

- 原圖優先：搜尋既有素材、保留原角色／敵人／Boss／場景；無原圖時優先恢復最早可用版本，不用簡化幾何圖形冒充原美術。
- 新美術風格明確要求時，維持整體角色、場景、敵人及介面的統一色彩與比例；可用動畫精靈圖、透明角色素材及清楚的前後景。只有在需要新圖片時才產生新素材，確認已實際整合；不以概念圖代替遊戲。
- 不強行重製外部作品或混用不同遊戲引擎。先檢查原始碼能否取得、修改及部署；缺少原碼則保持原版連結，說明需匯出原碼或確認重製。
- 動作遊戲依原版保留攻擊、閃避、蓄力、Boss 戰與命中表現；在適合的情況加入粒子、拖尾、命中閃白、震屏、勝利演出，避免遮住算式與答案。音效和背景音樂清晰，Boss 音樂可加速但保留可控音量。
- 教學內容始終優先於美術效果：文字及答案高對比、可從教室後排辨識；動畫不可妨礙閱讀或操作；手機按鍵集中於下方並兼顧鍵盤操作。

## 六個共用課程

| 單元 | 入口及空戰／螺絲戰機參數 | 指數劍客參數 |
|---|---|---|
| 指數律 | exp | exp |
| 分數四則 | frac | fraction |
| 一元一次式 | expr | algebra |
| 一元一次方程式 | eq | equation |
| 最大公因數與最小公倍數 | gcd | gcd |
| 正負數四則運算 | signed | signed |

使用 `?unit=<id>&mode=phone` 或 `mode=screen` 傳入設定，保留原連結其他查詢參數。只對已確認接受參數的遊戲自動帶入設定。其他遊戲維持原連結，清楚提示需在遊戲內確認，不要假裝支援。

- 指數律：正確上標、乘除、括號、加減及混合運算。
- 分數：使用上下分數與分數線，不以斜線當作主要視覺表示。
- 一元一次式：合併同類項、括號、多項式的基本化簡。
- 方程式：一步、兩步及兩邊含未知數，答案唯一。
- GCD／LCM：質因數分解標準式和由標準式求最大公因數、最小公倍數。
- 正負數：四則、括號及混合計算，除數非零，依教學難度控制答案範圍。

## 原美術優先、原設定不覆蓋

1. 先找到完整現有原始碼與實際圖片，尤其是主角、魔王、關卡地圖和場景；不要用無圖片的簡化重製版取代原作。
2. 螺絲戰機原圖版本來源是 `stnhhs2003-creator/equation-charge` 的根目錄 `index.html`；六單元版本位於 `six-units/index.html`。目前基準含五張內嵌圖片，保留圖片內容與其他未要求調整的玩法。
3. 優先修改題庫、單元選單、參數接收與數學呈現，保留美術、集氣射擊、原難度、關卡、角色、音樂和排行榜。新版本與原版保留可追溯關係。
4. 新增素材前優先搜尋已有專案素材。若原圖遺失或無法取得，保留或恢復最早可靠的原圖版本；不要擅自把無圖版本換上入口。
5. Claude 外部作品若沒有原始碼或檔案存取被拒絕，只保留連結和已確認資料；請使用者匯出檔案，或取得明確同意後另行重製。
6. 新建版本的排行榜使用獨立儲存鍵，避免混入原版資料。

## 手機、大屏與課堂操作

入口優先提供課程與裝置選擇，再進入遊戲，記住上次設定。手機支援 iPhone Safari 和觸控；大屏模式放大題目、資訊及必要按鍵，維持主要遊戲畫面的尺寸與比例，不因切換模式拉伸或遮住戰鬥場景。全螢幕另有開關。

維持課堂小組協作：一人操作，隊友計算並告知答案。題目上方固定且清楚，答案四選一直接顯示數學內容。戰鬥遊戲保留短按普通攻擊、長按集氣及實際命中才判題，不自動選正確答案。不同遊戲保留原有玩法，不強行統一成同一個引擎。

## 整合、驗收與發布

1. 先從正式入口和對應遊戲原始碼核對現況。僅修改使用者授權的儲存庫及路徑，保留其他遊戲名稱和連結。
2. 修改前確認最新版 SHA；寫入時使用對應版本，遇衝突先重讀，不強制覆蓋。
3. 驗證 HTML/JavaScript 語法；每個新增單元與難度抽樣至少 100 題，實際驗算正解、確認四個選項不重複、無除零、分數約分、題目格式可讀。不要只因選項包含答案便稱為數學正確。
4. 確認美術素材確實存在且正確載入；對原本內嵌圖片比較原始字節是否一致。驗證大屏與手機設定不改變場景比例。
5. 驗證開始、角色操作、題目切換、答題判定、勝負及返回入口。未完成整局或未在實體 iPhone／教室大屏實測時明確標記。
6. 部署至既有 GitHub Pages，等待發布完成。實際開啟正式網址，確認最新入口、目標遊戲、課程與裝置設定。如尚未發布則說明，勿把提交成功當部署成功。快取參數只能輔助，不代替驗證。
7. 最後提供一個八合一正式入口網址，簡短列出更新內容、保留版本與待驗證事項，不增加不必要的入口。

## 安全

## 共用配樂素材庫（Larch）
- 製作或更新遊戲時先讀儲存庫根目錄 `assets/music-catalog.json`，依主題及風格挑選曲目；同一來源網址不得重複登錄。
- 常用素材來源：https://larch.ink/ 。有新素材需求時提供官網讓使用者挑選。
- 官方通用授權允許成品使用但禁止原始素材獨立重分發；逐曲確認商城授權、是否第一方、署名及發布條件，並確認外部網址使用許可。`approvedForDeployment` 為 false 時不得下載到公開儲存庫、熱連結播放或整合發布。
- 正式使用前試聽，確認循環接點、音量、淡入淡出、Boss 切換及 iPhone 首次互動解鎖音訊；保留靜音及音量控制。不得因加入素材索引而自動修改現有遊戲。

## 十大遊戲共用音訊與原版保護規範
- 各款遊戲提供可選擇配樂（原版、已核准原創曲目、關閉）與獨立背景音樂／音效音量；新音訊功能預設35%／65%，記住使用者選擇。
- 優先讀取 `assets/music/catalog.json` 及 `assets/music/original-scores.json`；不得使用授權未確認的外部 MP3。
- 依各遊戲原有音訊引擎分別整合，避免重複播放。Safari 需使用者互動解鎖音訊，暫停及離開時停止排程。
- 不任意覆蓋美術、角色、場景、題庫、玩法、網址、既有原版配樂；修改前讀原始碼，僅改必要音訊區塊。外部 Claude 作品若無可編輯原始碼，保留連結並標示待整合。
- 部署前檢查原始碼差異、語法、音量、切換、原版音樂與手機／大屏操作；禁止將靜態檢查宣稱為實機測試。
