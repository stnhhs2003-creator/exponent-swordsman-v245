# 數學幻境｜課程主題一鍵整合

## 只輸入主題也能開始

將使用者提供的課程主題視為主要需求，例如「一元一次方程式」「分數四則」「圓心角與圓周角」。預設繁體中文（臺灣）、國中程度、由易到難、四選一且答案唯一。先核對現有單元與遊戲可用題庫。若沒有指定遊戲，依主題選擇最適合且有可靠原始碼的現有遊戲，以不覆蓋原版為優先；若需要選擇的情況確實會改變成果，才提出一個簡短問題。

預設以現行八合一為唯一入口；不要把新版本另列第九款，除非使用者明確要求增加新遊戲。保留原本遊戲入口與歷史版本，可透過既有遊戲卡片更新目標版本。

## 六個共用課程

| 單元 | 入口及空戰／螺絲戰機參數 | 指數劍客參數 |
|---|---|---|
| 指數律 | exp | exp |
| 分數四則 | frac | fraction |
| 一元一次式 | expr | algebra |
| 一元一次方程式 | eq | equation |
| 最大公因數與最小公倍數 | gcd | gcd |
| 正負數四則運算 | signed | signed |

使用 `?unit=<id>&mode=phone` 或 `mode=screen` 傳入設定，保留原連結其他查詢參數。只對已確認接受參數的遊戲自動帶入設定。其他遊戲維持原連結，清楚提示需在遊戲內確認，不要假裝支援。

- 指數律：正確上標、乘除、括號、加減及混合運算。
- 分數：使用上下分數與分數線，不以斜線當作主要視覺表示。
- 一元一次式：合併同類項、括號、多項式的基本化簡。
- 方程式：一步、兩步及兩邊含未知數，答案唯一。
- GCD／LCM：質因數分解標準式和由標準式求最大公因數、最小公倍數。
- 正負數：四則、括號及混合計算，除數非零，依教學難度控制答案範圍。

## 原美術優先、原設定不覆蓋

1. 先找到完整現有原始碼與實際圖片，尤其是主角、魔王、關卡地圖和場景；不要用無圖片的簡化重製版取代原作。
2. 螺絲戰機原圖版本來源是 `stnhhs2003-creator/equation-charge` 的根目錄 `index.html`；六單元版本位於 `six-units/index.html`。目前基準含五張內嵌圖片，保留圖片內容與其他未要求調整的玩法。
3. 優先修改題庫、單元選單、參數接收與數學呈現，保留美術、集氣射擊、原難度、關卡、角色、音樂和排行榜。新版本與原版保留可追溯關係。
4. 新增素材前優先搜尋已有專案素材。若原圖遺失或無法取得，保留或恢復最早可靠的原圖版本；不要擅自把無圖版本換上入口。
5. Claude 外部作品若沒有原始碼或檔案存取被拒絕，只保留連結和已確認資料；請使用者匯出檔案，或取得明確同意後另行重製。
6. 新建版本的排行榜使用獨立儲存鍵，避免混入原版資料。

## 手機、大屏與課堂操作

入口優先提供課程與裝置選擇，再進入遊戲，記住上次設定。手機支援 iPhone Safari 和觸控；大屏模式放大題目、資訊及必要按鍵，維持主要遊戲畫面的尺寸與比例，不因切換模式拉伸或遮住戰鬥場景。全螢幕另有開關。

維持課堂小組協作：一人操作，隊友計算並告知答案。題目上方固定且清楚，答案四選一直接顯示數學內容。戰鬥遊戲保留短按普通攻擊、長按集氣及實際命中才判題，不自動選正確答案。不同遊戲保留原有玩法，不強行統一成同一個引擎。

## 整合、驗收與發布

1. 先從正式入口和對應遊戲原始碼核對現況。僅修改使用者授權的儲存庫及路徑，保留其他遊戲名稱和連結。
2. 修改前確認最新版 SHA；寫入時使用對應版本，遇衝突先重讀，不強制覆蓋。
3. 驗證 HTML/JavaScript 語法；每個新增單元與難度抽樣至少 100 題，實際驗算正解、確認四個選項不重複、無除零、分數約分、題目格式可讀。不要只因選項包含答案便稱為數學正確。
4. 確認美術素材確實存在且正確載入；對原本內嵌圖片比較原始字節是否一致。驗證大屏與手機設定不改變場景比例。
5. 驗證開始、角色操作、題目切換、答題判定、勝負及返回入口。未完成整局或未在實體 iPhone／教室大屏實測時明確標記。
6. 部署至既有 GitHub Pages，等待發布完成。實際開啟正式網址，確認最新入口、目標遊戲、課程與裝置設定。如尚未發布則說明，勿把提交成功當部署成功。快取參數只能輔助，不代替驗證。
7. 最後提供一個八合一正式入口網址，簡短列出更新內容、保留版本與待驗證事項，不增加不必要的入口。
